Test Users Reference & Run Guide

How to Run

  1. Open the project folder Project07_04 in VS Code.
  2. Right-click index.html → "Open with Live Server" (requires Live Server extension). This is required because HTML views are loaded dynamically.
  3. The login page will appear. Use any credentials from the tables below.
  4. To view the database, click the "Database Viewer" link at the bottom of the sidebar after logging in, or open db-viewer.html directly.
No server installation needed, but you must use VS Code Live Server (or any local HTTP server) because the app loads HTML view partials via fetch(). The database runs entirely in the browser using sql.js persisted in localStorage. To reset all data, clear localStorage in DevTools → Application → Local Storage → delete hms_database.
